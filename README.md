# Project Ulduar

A vault and observatory for data projects. Project Ulduar is a generic Python library and CLI that will
give a data project an immutable archive of what went in and what came out, a catalog of what exists
and where it came from, a record of every run, and a verdict on whether the data is fresh, complete
and recoverable.

**Status: planned, nothing built.** `ROADMAP.md` holds the plan, the open sign-off items and the status.

## Components

Named after the keepers and watchers of Ulduar, the titan vault in Warcraft lore.

| Component | Role |
|---|---|
| **Freya** | Catalog and lineage |
| **Hodir** | Cold archive, retention, integrity and restore verification |
| **Thorim** | Run ledger |
| **Algalon** | Monitoring: verdicts and alerts |
| **Mimiron** | CLI, connectors and the GitHub Action |
